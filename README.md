# نظام كرافت لاند المحاسبي

🔗 **رابط النظام:** https://sacraftland.github.io/accounting/

نظام محاسبي وتصنيعي كامل باللغة العربية، يعمل من المتصفح على الكمبيوتر والجوال، ومتوافق مع ضريبة القيمة المضافة والفوترة الإلكترونية في السعودية (المرحلة الأولى).

## ما في النظام

| القسم | المحتوى |
|---|---|
| **المبيعات** | نقطة البيع (كاشير بإيصال حراري 80مم وQR)، فواتير ضريبية ومبسطة برمز QR، عروض أسعار تتحول لفاتورة، إشعارات دائنة (مرتجعات)، سندات قبض، العملاء وكشوف حساباتهم |
| **المشتريات** | فواتير مشتريات مع توزيع الشحن والجمارك على التكلفة وخيار السداد الفوري، أوامر شراء، مرتجعات مشتريات، سندات صرف، الموردون وكشوفهم |
| **المصروفات** | الإيجار والكهرباء والوقود… مع ضريبة المدخلات، من الصندوق أو البنك أو العهدة |
| **المخزون** | عدة مستودعات، أرصدة لكل مستودع، تحويل، جرد وتسوية، تالف، أرصدة افتتاحية، متوسط التكلفة المرجّح، منع البيع بدون رصيد (اختياري) |
| **التصنيع** | قوائم المواد بنسب الهدر، أوامر تصنيع حسب الطلب أو للمخزون، المخطط والمستهلك والتالف، تكاليف العمالة والتشغيل، تكلفة الوحدة وهامش الربح |
| **المشاريع** | مركز تكلفة لكل كرفان أو عقد أو قسم، وإيراداته وتكاليفه وربحه ونسبة إنجازه |
| **المالية** | شجرة حسابات سعودية، قيود يومية آلية ويدوية وعكسها، ميزان المراجعة |
| **التقارير** | قائمة الدخل (مع مقارنة)، المركز المالي، الإقرار الضريبي بترتيب نموذج الهيئة، أعمار الذمم، تقييم المخزون، تقرير الإنتاج — تصدير Excel وطباعة PDF |
| **الموارد البشرية** | الموظفون، مسير الرواتب الشهري، التأمينات الاجتماعية (سعودي / غير سعودي)، مخصص نهاية الخدمة، الإضافي والخصومات، ملف تحويل الرواتب |
| **المستخدمون** | الدخول بالدعوة فقط، أدوار مرنة بصلاحيات (عرض / إنشاء / اعتماد) لكل قسم، دورة اعتماد، عدة شركات |

## البدء

دليل الاستخدام خطوة بخطوة: [docs-setup.md](docs-setup.md).

## الملفات

- `index.html` — النظام كاملاً في ملف واحد (هذا ما يعمل على GitHub Pages)
- `supabase/` — قاعدة البيانات بالترتيب `01` … `08` (و`setup.sql` يجمعها لمشروع جديد)
- `src/` — الأجزاء التي يُبنى منها الملف + الاختبارات (`python3 src/app/build.py <url> <publishable-key>`)

## الأمان

- المفتاح الموجود في `index.html` هو المفتاح العام (publishable) فقط.
- كل قاعدة في الصلاحيات مفروضة داخل قاعدة البيانات (Row Level Security ودوال ترحيل تتحقق من الصلاحية)، لا في الواجهة فقط.
- المستند المرحّل لا يُعدَّل — يُصحَّح بإشعار دائن أو مرتجع أو قيد عكسي.
- الاختبارات: 182 فحصاً على قاعدة البيانات و167 فحصاً على الواجهة (`src/tests`).
