# نظام كرافت لاند المحاسبي

🔗 **رابط النظام:** https://sacraftland.github.io/accounting/

نظام محاسبي وتصنيعي كامل باللغة العربية، يعمل من المتصفح على الكمبيوتر والجوال، ومتوافق مع ضريبة القيمة المضافة والفوترة الإلكترونية في السعودية (المرحلة الأولى).

## ما في النظام

| القسم | المحتوى |
|---|---|
| **المبيعات** | نقطة البيع (كاشير بإيصال حراري 58 أو 80 ملم وQR، وطباعة مباشرة على طابعات أجهزة POS الأندرويد عبر RawBT، وإعادة طباعة أي فاتورة كإيصال حراري)، فواتير ضريبية ومبسطة برمز QR، عروض أسعار تتحول لسند تسليم أو فاتورة، سندات تسليم، إشعارات دائنة (مرتجعات)، سندات قبض، تسوية مدفوعات الشبكة (مدى)، العملاء وكشوف حساباتهم وحد الائتمان وتذكير السداد بواتساب والبريد، **بوابة العميل** (رابط كشف حساب بدون تسجيل دخول) |
| **العملاء المحتملون** | لوحة مراحل المتابعة، القيمة المتوقعة، مواعيد المتابعة، التحويل لعميل |
| **المشتريات** | فواتير مشتريات مع توزيع الشحن والجمارك على التكلفة وخيار السداد الفوري، أوامر شراء، مرتجعات مشتريات، سندات صرف، الموردون وكشوفهم |
| **المصروفات** | الإيجار والكهرباء والوقود… مع ضريبة المدخلات، من الصندوق أو البنك أو العهدة؛ **الصندوق والعهد**: صرف عهدة لموظف واستردادها |
| **المخزون** | عدة مستودعات، أرصدة لكل مستودع، تحويل، جرد وتسوية، تالف، أرصدة افتتاحية، متوسط التكلفة المرجّح، منع البيع بدون رصيد (اختياري)، ورقة جرد Excel تصدير واستيراد، **رحلات المندوبين** (تحميل، بيع من السيارة، إرجاع، تسوية النقد) |
| **التصنيع** | قوائم المواد بنسب الهدر، أوامر تصنيع حسب الطلب أو للمخزون، المخطط والمستهلك والتالف، تكاليف العمالة والتشغيل، تكلفة الوحدة وهامش الربح |
| **المهام والمشاريع** | مركز تكلفة لكل كرفان أو عقد أو قسم بإيراداته وتكاليفه وربحه، مهام لكل مشروع بمسؤول وتاريخ استحقاق ونسبة إنجاز، لوحة مهام |
| **المتابعة** | الالتزامات والتجديدات (السجل التجاري، الرخص، الإقامات، التأمين…) مع تنبيه قبل الانتهاء، تقويم ميلادي وهجري بالملاحظات |
| **المالية** | شجرة حسابات سعودية قابلة للإضافة، كشف حساب لكل حساب، الأرصدة الافتتاحية، قيود يومية آلية ويدوية وعكسها، ميزان المراجعة، **الأصول الثابتة** بإهلاك شهري تلقائي وبيع / استبعاد |
| **التقارير** | قائمة الدخل (مع مقارنة)، المركز المالي، الإقرار الضريبي بترتيب نموذج الهيئة، أعمار الذمم، تقييم المخزون، تقرير الإنتاج، التدفقات النقدية، التحليل المقارن 12 شهراً، الموازنة التقديرية مقابل الفعلي، المؤشرات المالية ومؤشر ألتمان وتقدير الزكاة — تصدير Excel وطباعة PDF |
| **الموارد البشرية** | الموظفون، مسير الرواتب الشهري، التأمينات الاجتماعية (سعودي / غير سعودي)، مخصص نهاية الخدمة، الإضافي والخصومات، ملف تحويل الرواتب، الإجازات واعتمادها وأرصدتها، الحضور والانصراف، تقييم الأداء |
| **الفروع والاستيراد** | فروع بمستودعاتها ومبيعاتها، استيراد العملاء والموردين والأصناف من Excel (CSV) مع معاينة |
| **دراسات الجدوى** | تكاليف ومواد وأجور وسعر بيع من السجل أو يدوياً أو من الذكاء الاصطناعي (تصدير واستيراد)، سيناريوهات، صافي القيمة الحالية ومعدل العائد الداخلي، تقرير مطبوع |
| **منشئ التقارير** | 12 مصدر بيانات و13 قالباً جاهزاً، تجميع وجداول محورية وفلاتر، حفظ التقارير، Excel وCSV وطباعة |
| **النسخ الاحتياطي** | نسخة كاملة بضغطة وتصدير Excel لكل الجداول، استرجاع لشركة جديدة أو مكان الحالية، برنامج نسخ تلقائي ليلي للينكس، حزمة تثبيت كاملة، **تصفير الشركة** لإنهاء فترة التجربة (العمليات فقط أو كل شيء، بنسخة احتياطية إلزامية قبله) |
| **المستخدمون** | الدخول بالدعوة فقط (بريد أو Google)، أدوار مرنة بصلاحيات (عرض / إنشاء / اعتماد) لكل قسم، دورة اعتماد، عدة شركات |

## البدء

دليل الاستخدام خطوة بخطوة: [docs-setup.md](docs-setup.md). ولتثبيت نسخة جديدة مستقلة: نزّل [حزمة التثبيت](install/craftland-install.zip) وافتح `دليل-التثبيت.html` بداخلها.

## الملفات

- `index.html` — النظام كاملاً في ملف واحد (هذا ما يعمل على GitHub Pages)
- `supabase/` — قاعدة البيانات بالترتيب `01` … `19` (و`setup.sql` يجمعها لمشروع جديد)
- `install/craftland-install.zip` — **حزمة التثبيت الكاملة**: البرنامج بدون مفاتيح، قاعدة البيانات، الأدلة خطوة بخطوة، برنامج النسخ الاحتياطي، والكود المصدري (تُنزَّل أيضاً من داخل البرنامج: الإعدادات ← النسخ الاحتياطي)
- `tools/craftland-backup.py` — برنامج النسخ الاحتياطي التلقائي (قالب — حمّل النسخة الجاهزة من داخل البرنامج)
- `src/` — الأجزاء التي يُبنى منها الملف + الاختبارات (`python3 src/app/build.py <url> <publishable-key>`)

## الأمان

- المفتاح الموجود في `index.html` هو المفتاح العام (publishable) فقط.
- كل قاعدة في الصلاحيات مفروضة داخل قاعدة البيانات (Row Level Security ودوال ترحيل تتحقق من الصلاحية)، لا في الواجهة فقط.
- المستند المرحّل لا يُعدَّل — يُصحَّح بإشعار دائن أو مرتجع أو قيد عكسي.
- الاختبارات: 378 فحصاً على قاعدة البيانات و56 فحصاً لملفات الهيئة و416 فحصاً على الواجهة (`src/tests`).
