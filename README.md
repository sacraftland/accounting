# نظام كرافت لاند المحاسبي

🔗 **رابط النظام:** https://sacraftland.github.io/accounting/

- `index.html` — النظام كاملاً في ملف واحد (هذا ما يعمل على GitHub Pages)
- `supabase/` — قاعدة البيانات (مطبّقة على مشروع Supabase `craftland-accounting`)
- `src/` — الأجزاء التي يُبنى منها الملف + الاختبارات (`python3 src/app/build.py`)
- `docs-setup.md` — خطوات الإعداد (Supabase، Google، GitHub Pages)

المفتاح الموجود في `index.html` هو المفتاح العام (publishable) فقط، والحماية مفروضة داخل قاعدة البيانات.
