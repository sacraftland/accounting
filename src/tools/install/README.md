# كرافت لاند — حزمة التثبيت الكاملة

هذه الحزمة فيها **البرنامج كاملاً**: الواجهة، وقاعدة البيانات، والأدلة، وأداة النسخ الاحتياطي. تقدر تثبّت منها نسخة جديدة مستقلة في أي وقت: لك، أو لشركة ثانية، أو لعميل تبيعه النظام، أو لو احتجت تبدأ من الصفر على خادم جديد.

> **ابدأ من هنا:** افتح `دليل-التثبيت.html` بالضغط عليه مرتين. فيه كل الأدلة في صفحة واحدة مرتبة ومنسّقة.

---

## ما في الحزمة

| المجلد / الملف | وش هو | متى تحتاجه |
|---|---|---|
| `دليل-التثبيت.html` | كل الأدلة في صفحة واحدة | **أول شيء تفتحه** |
| `app/index.html` | **البرنامج نفسه** في ملف واحد (بدون مفاتيح ربط) | ترفعه على الاستضافة |
| `app/privacy.html` | صفحة سياسة الخصوصية | ترفعها مع البرنامج |
| `database/setup.sql` | **قاعدة البيانات كاملة**: كل الجداول والصلاحيات والمعادلات | تثبيت جديد — مرة واحدة |
| `database/owner.sql` | سطر يحدد بريد مالك النظام | بعد setup.sql مباشرة |
| `database/check.sql` | فحص أن التثبيت تم صحيحاً | بعد owner.sql |
| `database/migrations/` | نفس قاعدة البيانات مقسّمة على 16 تحديثاً مرتباً | لتحديث نسخة قديمة فقط |
| `tools/craftland-backup.py` | برنامج النسخ الاحتياطي التلقائي (لينكس) | اختياري |
| `docs/` | الأدلة منفصلة (نفس محتوى ملف HTML) | مرجع |
| `source/` | الكود المصدري + الاختبارات (للمطوّر) | لتعديل البرنامج وإعادة بنائه |
| `VERSION.txt` | رقم الإصدار وتاريخه ومستوى قاعدة البيانات | للمقارنة بين النسخ |
| `SHA256SUMS.txt` | بصمة كل ملف | للتأكد أن الملفات سليمة |

## ما تحتاجه للتثبيت

- حساب **Supabase** (مجاني للبداية) — قاعدة البيانات وتسجيل الدخول.
- حساب **GitHub** (مجاني) — لاستضافة البرنامج. أو أي استضافة ملفات ثابتة تدعم HTTPS.
- بريد **Gmail** مع «كلمة مرور تطبيق» — لإرسال رسائل التأكيد واستعادة كلمة المرور.
- (اختياري) مشروع في **Google Cloud** — لزر «الدخول بحساب Google».
- (اختياري) نطاق خاص مثل `accounting.craftland.sa`.

المدة: **30 إلى 45 دقيقة** أول مرة.

## تنبيهات مهمة

- **لا تضع أبداً** مفتاح `service_role` أو `secret` من Supabase داخل `index.html`. البرنامج يحتاج المفتاح العام فقط (publishable / anon).
- `setup.sql` **لتثبيت جديد فقط**. لا تشغّله على قاعدة بيانات فيها بيانات — للتحديث استخدم `migrations/`.
- ملف النسخة الاحتياطية للبيانات (`.json.gz`) ليس جزءاً من هذه الحزمة — هذه الحزمة هي **البرنامج**، والنسخة الاحتياطية هي **البيانات**. احفظ الاثنين.
