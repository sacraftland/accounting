# ٢. أول يوم في النظام

بعد التثبيت، رتّب النظام بهذا الترتيب — كل خطوة تعتمد على اللي قبلها.

| # | المكان في البرنامج | وش تسوي |
|---|---|---|
| 1 | **الإعدادات** | بيانات المنشأة، الرقم الضريبي، العنوان الوطني، الشعار، تذييل الفاتورة، والسماح بالبيع بدون رصيد أو لا |
| 2 | **الإعدادات ← تصميم الفاتورة** | القالب واللون والختم والتوقيع وبيانات البنك والشروط |
| 3 | **المستخدمون والصلاحيات** | أدوار (محاسب، أمين مخزن، مشرف ورشة…) بصلاحيات «عرض / إنشاء / اعتماد» لكل قسم، ثم ادعُ الموظفين بإيميلاتهم |
| 4 | **الفروع والمستودعات** | الفروع (لكل فرع مستودع)، ومستودعات المواد الخام والورشة والمعرض |
| 5 | **استيراد من Excel** | العملاء والموردون والأصناف — نزّل القالب، عبّئه، وارفع ملف Excel مباشرة |
| 6 | **حركات المخزون ← رصيد افتتاحي** | الكميات الموجودة وتكلفتها (أو ورقة جرد Excel) |
| 7 | **شجرة الحسابات ← الأرصدة الافتتاحية** | الصندوق والبنك ورأس المال وأرصدة العملاء والموردين |
| 8 | **الأصول الثابتة** | المكائن والسيارات والمعدات بتكلفتها وعمرها |
| 9 | **قوائم المواد** | مكونات كل منتج تصنعه ونسب الهدر |
| 10 | **الموظفون** | الرواتب والبدلات والآيبان، ونوع التوظيف (شهري / يومي / بالساعة) |
| 11 | **المشاريع** | مشروع لكل كرفان أو عقد، بمواده ومهامه وعماله |
| 12 | **الالتزامات والتجديدات** | السجل التجاري، الرخص، الإقامات، التأمين — يذكّرك قبل انتهائها |
| 13 | **النسخ الاحتياطي** | نزّل أول نسخة، وجهّز النسخ التلقائي (`5-النسخ-والاسترجاع.md`) |

## العمل اليومي

فواتير الشراء ← صرف المواد للمشاريع وساعات العمل ← عروض الأسعار والفواتير أو نقطة البيع ← سندات القبض والصرف ← المصروفات.

**آخر الشهر:** مسير الرواتب، الإهلاك، ترحيل أجور المشاريع، والتقارير (قائمة الدخل، المركز المالي، الإقرار الضريبي، التدفقات النقدية).

## دورة الاعتماد

من عنده صلاحية «إنشاء» بدون «اعتماد» يحفظ المستند ويضغط **إرسال للاعتماد**، فيظهر لمن يملك الاعتماد في لوحة التحكم تحت «بانتظار اعتمادك». ما يُسجَّل أي قيد حتى يُعتمد.

## أدوات تستحق التجربة

- **منشئ التقارير:** أي تقرير تبيه من 12 مصدر بيانات، مع 13 قالباً جاهزاً، وتصدير Excel.
- **دراسات الجدوى:** قبل أي منتج أو استثمار جديد.
- **لوحة الورشة (شاشة):** على تلفزيون الورشة — مهام اليوم والمشاريع.
- **بوابة العميل:** رابط كشف حساب للعميل بدون تسجيل دخول.
- **رحلات المندوبين:** تحميل، بيع من السيارة، إرجاع، تسوية النقد.
