# ٥. النسخ الاحتياطي والاسترجاع

## الفرق بين النسختين

| | **حزمة التثبيت** (هذه) | **النسخة الاحتياطية للبيانات** |
|---|---|---|
| فيها | البرنامج + هيكل قاعدة البيانات + الأدلة | كل بياناتك: الحسابات، القيود، الفواتير، المخزون، الموظفين، المشاريع، الإعدادات |
| الملف | `craftland-install-….zip` | `craftland-….json.gz` |
| من وين | الإعدادات ← النسخ الاحتياطي ← تنزيل حزمة التثبيت | الإعدادات ← النسخ الاحتياطي ← تنزيل نسخة كاملة |
| متى تتغير | مع كل إصدار جديد | كل يوم تشتغل فيه |

**احفظ الاثنين.** بالحزمة تثبّت البرنامج من الصفر، وبالنسخة ترجّع بياناتك فيه.

## نسخة يدوية

**الإعدادات ← النسخ الاحتياطي:**
- **تنزيل نسخة احتياطية كاملة** — ملف واحد مضغوط، يُسترجع من نفس الصفحة.
- **تصدير كل الجداول إلى Excel** — ورقة لكل جدول، للاطلاع والتحليل (المبالغ بالهللة: اقسم على 100). للاسترجاع استخدم ملف النسخة وليس Excel.

## الاسترجاع

**الإعدادات ← النسخ الاحتياطي ← استرجاع نسخة** ← اختر الملف ← تظهر معاينة (اسم الشركة، تاريخ النسخة، عدد السجلات) ← اختر:

| الطريقة | ماذا يحدث | متى |
|---|---|---|
| **كشركة جديدة** | تظهر النسخة كشركة منفصلة، وبياناتك الحالية كما هي. تنتقل بينهما من قائمة الشركات | للمقارنة، أو نقل البيانات لتثبيت جديد |
| **بدلاً من الشركة الحالية** | تصير النسخة هي الشركة المستخدمة، وينتقل لها كل الموظفين بنفس أدوارهم. القديمة **لا تُحذف**: تبقى «أرشيف» للمالك فقط | لو تلفت البيانات أو حُذف شيء بالغلط |

- «بدلاً من الحالية» تطلب كتابة اسم الشركة للتأكيد، وللمالك فقط.
- النظام يرفض أي ملف معدّل أو ناقص أو فيه بيانات تشير لشركة أخرى — ولا يكتب شيئاً إذا فشل.

## النسخ التلقائي كل ليلة (لينكس)

برنامج `tools/craftland-backup.py` يشتغل على أي كمبيوتر لينكس متصل بالإنترنت: كل ليلة الساعة 2:30 يسحب نسخة كاملة، يتحقق منها، ويحتفظ بآخر **30 نسخة يومية + نسخة لكل شهر لمدة 12 شهراً**. يحتاج Python 3 فقط (موجود في Ubuntu افتراضياً).

> الملف في `tools/` قالب. **حمّل النسخة الجاهزة من داخل البرنامج** (الإعدادات ← النسخ الاحتياطي ← `craftland-backup.py`) لأنها تحمل عنوان مشروعك ورقم شركتك.

**الإعداد مرة واحدة:**

1. **حساب خاص للنسخ:** في صفحة النسخ الاحتياطي اضغط «إنشاء دور النسخ الاحتياطي»، ثم من **المستخدمون** ادعُ بريداً مخصصاً بهذا الدور (مثلاً `اسمك+backup@gmail.com` — رسائله توصل لبريدك نفسه). سجّل به من البرنامج وضع كلمة مرور قوية. هذا الحساب ينسخ فقط، ولا يرى أو يعدّل أي شاشة.
2. انقل `craftland-backup.py` للكمبيوتر، وافتح **Terminal** في نفس المجلد:

| الأمر | ماذا يفعل |
|---|---|
| `python3 craftland-backup.py setup` | يسأل البريد وكلمة المرور ومجلد الحفظ (وقرص ثاني اختياري)، ثم نسخة أولى |
| `python3 craftland-backup.py install` | تشغيل تلقائي كل ليلة |
| `python3 craftland-backup.py status` | آخر النسخ وموعد القادمة |
| `python3 craftland-backup.py verify` | فحص سلامة آخر نسخة |
| `python3 craftland-backup.py run` | نسخة الآن |
| `python3 craftland-backup.py uninstall` | إيقاف التشغيل التلقائي (النسخ تبقى) |

كل نسخة ناجحة تظهر في البرنامج تحت «آخر نسخة من كمبيوتر النسخ»، وإذا تأخرت أكثر من يوم ونصف يظهر تنبيه.

## روتين مقترح

- **يومياً:** النسخ التلقائي (أو يدوي في نهاية يوم عمل كبير).
- **أسبوعياً:** انسخ آخر ملف لقرص خارجي أو Google Drive.
- **شهرياً:** جرّب استرجاع نسخة **كشركة جديدة** وتأكد أن الأرقام مطابقة، ثم احذف الشركة التجريبية من قائمة الشركات. النسخة اللي ما جرّبت استرجاعها ما تعرف إذا تشتغل.
- **مع كل إصدار جديد:** نزّل حزمة التثبيت الجديدة.
