# ٣. بنية النظام

## الصورة الكاملة

```
 المتصفح (كمبيوتر أو جوال)                 Supabase (السحابة)
┌──────────────────────────┐          ┌───────────────────────────────┐
│  index.html — ملف واحد    │  HTTPS   │  تسجيل الدخول (Auth)           │
│  • كل الشاشات              │ ───────▶ │  قاعدة بيانات PostgreSQL       │
│  • الطباعة والتقارير        │ ◀─────── │  • 55 جدولاً                   │
│  • الحسابات على الشاشة     │          │  • 160 دالة (الترحيل والتقارير) │
│  • المفتاح العام فقط        │          │  • 104 قاعدة صلاحيات (RLS)     │
└──────────────────────────┘          │  • 27 حارس على الجداول         │
          ▲                            └───────────────────────────────┘
          │ ملف ثابت                                ▲
   GitHub Pages (الاستضافة)            craftland-backup.py (نسخ ليلي)
```

- **الواجهة** ملف HTML واحد، بدون خادم خاص بك. كل ما يعرضه يأتي من قاعدة البيانات حسب صلاحيات المستخدم.
- **قاعدة البيانات** هي «عقل» النظام: كل ترحيل (فاتورة، سند، قيد، مخزون، رواتب) يتم بدالة داخلها تتحقق من الصلاحية وتوازن القيد، فلا يمكن التلاعب بالأرقام من المتصفح.
- **تعدد الشركات:** كل سجل مربوط بـ `org_id`، وكل مستخدم يرى شركاته فقط.

## قواعد ثابتة في التصميم

| القاعدة | المعنى |
|---|---|
| المبالغ بالهللة | كل مبلغ عدد صحيح (1 ريال = 100). لا أخطاء تقريب |
| المرحّل لا يُعدَّل | الفاتورة أو القيد بعد الترحيل لا يتغير — يُصحَّح بإشعار دائن أو مرتجع أو قيد عكسي |
| التكلفة بالمتوسط المرجّح | لكل صنف، عبر كل المستودعات |
| التواريخ بتوقيت الرياض | تواريخ المستندات، والأوقات تُحفظ بتوقيت عالمي |
| الصلاحية في قاعدة البيانات | إخفاء زر في الواجهة ليس حماية — الحماية في RLS والدوال |

## الصلاحيات

كل دور فيه لكل قسم ثلاث درجات: **عرض** (يشوف) — **إنشاء** (يسوي مسودات ويعدلها) — **اعتماد** (يرحّل ويكتب القيد). المالك عنده كل شيء.

| المفتاح | القسم |
|---|---|
| `sales` | المبيعات والعملاء ونقطة البيع |
| `purchases` | المشتريات والموردون |
| `expenses` | المصروفات والعهد |
| `inventory` | المخزون والمستودعات والجرد |
| `manufacturing` | التصنيع والمشاريع والمهام |
| `accounting` | القيود وشجرة الحسابات والأصول |
| `reports` | التقارير ومنشئ التقارير |
| `hr` | الموظفون والرواتب والإجازات والحضور |
| `settings` | إعدادات الشركة والتصميم |
| `users` | المستخدمون والأدوار والدعوات |
| `feasibility` | دراسات الجدوى |
| `backup` | النسخ الاحتياطي (دور «النسخ الاحتياطي» = هذا فقط) |

## جداول قاعدة البيانات حسب المجال

| المجال | الجداول |
|---|---|
| الشركة والمستخدمون | `orgs` الشركات · `members` الأعضاء · `roles` الأدوار · `invitations` الدعوات · `platform_admins` ملاك النظام · `platform_settings` · `branches` الفروع · `counters` الترقيم · `audit_log` سجل التدقيق |
| المحاسبة | `accounts` شجرة الحسابات · `journal_entries` القيود · `journal_lines` أسطرها · `budgets` الموازنات · `fixed_assets` الأصول · `asset_depreciation` الإهلاك |
| المبيعات والمشتريات | `parties` العملاء والموردون · `documents` الفواتير وعروض الأسعار والأوامر والإشعارات · `document_lines` أسطرها · `payments` سندات القبض والصرف · `payment_allocations` توزيعها على الفواتير · `price_lists` و `price_list_items` قوائم الأسعار · `landed_costs` تكاليف الاستيراد · `leads` العملاء المحتملون · `portal_links` روابط بوابة العميل |
| نقطة البيع والفوترة | `pos_registers` نقاط البيع · `pos_shifts` الورديات · `zatca_devices` أجهزة الفوترة الإلكترونية · `van_trips` رحلات المندوبين |
| المصروفات | `expenses` المصروفات |
| المخزون | `items` الأصناف · `warehouses` المستودعات · `stock_moves` حركات المخزون · `stock_docs` و `stock_doc_lines` مستندات المخزون (تحويل، جرد، تالف، صرف لمشروع) |
| التصنيع والمشاريع | `boms` و `bom_lines` قوائم المواد · `mfg_orders` و `mfg_order_lines` و `mfg_order_costs` أوامر التصنيع · `cost_centers` المشاريع ومراكز التكلفة · `project_materials` مواد المشاريع · `tasks` المهام · `timesheets` ساعات العمل |
| الموارد البشرية | `employees` الموظفون · `payroll_runs` مسيرات الرواتب · `payslips` القسائم · `leaves` الإجازات · `attendance` الحضور · `evaluations` التقييمات |
| المتابعة | `commitments` الالتزامات والتجديدات · `calendar_notes` ملاحظات التقويم · `reminders` التذكيرات |
| التحليل | `feasibility_studies` دراسات الجدوى · `saved_reports` التقارير المحفوظة · `backup_log` سجل النسخ الاحتياطي |

## تحديثات قاعدة البيانات (migrations)

`setup.sql` = هذه الملفات الستة عشر مدموجة بالترتيب.

| الملف | ما يضيفه |
|---|---|
| `01_schema.sql` | الأساس: الشركات، شجرة الحسابات، القيود، العملاء، الأصناف، الفواتير، الترحيل، الضريبة، نقطة البيع، الفوترة الإلكترونية |
| `02_supabase.sql` | ربط Supabase: المستخدمون، منع تسرب البيانات بين الشركات، صلاحيات الجداول |
| `03_pin_search_path.sql` | تحصين الدوال (توصية أمان من Supabase) |
| `04_invitations.sql` | الدخول بالدعوة فقط، ملاك النظام |
| `05_permissions.sql` | الأدوار المرنة: عرض / إنشاء / اعتماد لكل قسم |
| `06_operations.sql` | المشتريات والمرتجعات، عروض الأسعار والأوامر، المصروفات، القيود اليدوية، المستودعات، التصنيع |
| `07_reports_payroll.sql` | التقارير المالية والإقرار الضريبي، الرواتب والتأمينات ونهاية الخدمة |
| `08_projects.sql` | ربحية المشاريع (مراكز التكلفة) |
| `09_extended.sql` | كشف الحساب، الأصول والإهلاك، العهد، تسوية الشبكة، سندات التسليم، الموازنات، العملاء المحتملون، المهام، الالتزامات، التقويم، الإجازات، الحضور، التقييم، الفروع، قوائم الأسعار |
| `10_portal_trips.sql` | بوابة العميل، رحلات المندوبين |
| `11_projects_pro.sql` | المشاريع المتقدمة: الأنواع، القوالب، المواد المخططة والمصروفة، الساعات، ترحيل الأجور |
| `12_casual_labor.sql` | العمال باليومية والساعة، الورش الخارجية |
| `13_design_dashboards.sql` | تصميم الفاتورة المطبوعة، لوحة تحكم لكل دور |
| `14_feasibility.sql` | دراسات الجدوى |
| `15_backup_reports.sql` | النسخ الاحتياطي والاسترجاع، منشئ التقارير |
| `16_hardening.sql` | تشديد صلاحيات الجداول: الزائر بدون حساب لا يصل لأي جدول |
| `17_reset.sql` | تصفير الشركة (للمالك): مسح بيانات التجربة قبل البدء الرسمي |

| المسار | وش فيه |
|---|---|
| `app/build.py` | يبني `index.html` من الأجزاء: `python3 app/build.py <Project URL> <Publishable key>` (بدون مفاتيح = يطلب الربط من الشاشة) |
| `app/config.js` · `data.js` | الربط بقاعدة البيانات وكل استدعاءاتها |
| `app/app.js` | الهيكل، القائمة، الصفحات الأساسية، لوحة التحكم، المبيعات |
| `app/ops.js` | المشتريات، المخزون، التصنيع، الصلاحيات |
| `app/reports.js` · `reports2.js` | التقارير المالية، الرواتب، الأصول |
| `app/pos.js` | نقطة البيع |
| `app/ext.js` · `ext2.js` · `ext3.js` | العهد، الموازنة، العملاء المحتملون، الإجازات، الاستيراد، الفروع، البوابة، الرحلات |
| `app/projects.js` | المشاريع والمهام والساعات |
| `app/theme.js` · `design.js` | المظهر، تخصيص لوحة التحكم، تصميم الفاتورة، شاشة الورشة |
| `app/feasibility.js` | دراسات الجدوى |
| `app/backup.js` · `reportbuilder.js` | النسخ الاحتياطي والاسترجاع، منشئ التقارير، كاتب ملفات Excel |
| `app/app.css` · `design/primitives.html` | التصميم والألوان والأيقونات |
| `supabase/` | ملفات قاعدة البيانات |
| `tests/` | الاختبارات (قاعدة البيانات + الواجهة) |

```bash
python3 tests/test_backup_script.py       # برنامج النسخ الاحتياطي
```
